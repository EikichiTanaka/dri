# INITIAL D ARCADE STAGE - 峠ドリフトレース 完全再現

SEGAの名作アーケードゲーム『頭文字D ARCADE STAGE』の独特かつ爽快なアーケードドリフト挙動、名峰・秋名峠の完全再現コース、白熱のライバルバトル、そして迫力のHUD＆サウンドを完全再現した本格3Dレースゲームです。

---

## 起動方法

### 方法 1: ワンクリック起動（推奨）
フォルダ内にある **`start_game.bat`** をダブルクリックしてください。
自動的にローカルサーバーが立ち上がり、お使いのブラウザでゲーム画面が開きます。

### 方法 2: コマンドラインからの起動
```bash
python run_game.py
```
ブラウザで `http://localhost:8000` にアクセスしてください。

## 難易度設定（DIFFICULTY）

スタート画面からプレイヤーの腕前に合わせた難易度を選択可能です。

- **EASY (初級)**:
  - 初心者でもしっかりブロック・追い抜きができ、勝つ喜びを味わえる設定。
- **NORMAL (白熱・推奨)**:
  - プレイヤーのハチロクと互角のスタートダッシュ！ヘアピンでの突っ込み勝負など、手に汗握る白熱のドッグファイトが楽しめます。
- **HARD (原作再現)**:
  - 高橋啓介のFD3Sが本気で攻めてくる、原作さながらの超ハイレベルバトル！

## 操作方法

キーボードおよび各社ゲームコントローラー（Xbox、PlayStation、一般USBゲームパッド）のアナログ入力に完全対応しています。

| 操作 | キーボード | ゲームパッド (コントローラー) |
|---|---|---|
| **ステアリング (操舵)** | `A` (左折) / `D` (右折) | 左スティック / 十字キー |
| **アクセル (加速)** | `W` または `↑` | `RT` (右トリガー) / `A` ボタン |
| **ブレーキ (安全減速)** | `S` または `↓` | `LT` (左トリガー) / `B` ボタン |
| **サイドブレーキ (ドリフト)** | `SPACE` | `RB` (右バンパー) / `X` ボタン |
| **シフトアップ (MT)** | `→` (右矢印) / `E` / `SHIFT` | `Y` ボタン / 右パドル |
| **シフトダウン (MT)** | `←` (左矢印) / `Q` / `CTRL` (リアルなエンブレ再現) | `X` ボタン / 左パドル |
| **視点切り替え** | `C` (後方追従 / 近接 / ボンネット主観) | 視点切り替えボタン |
| **コーナーアシスト切替** | `T` (弱：標準 / 強：超旋回) | - |
| **ヘッドライト / リトラ開閉** | `L` | バックボタン |
| **リトライ (リセット)** | `R` | - |

## コーナーアシスト設定（CORNER ASSIST）

プレイスタイルに合わせてコーナーでの旋回アシストの強弱を設定可能です（スタート画面および走行中に `T` キーでいつでも即座に切替可能）。

- **弱 (標準・マイルド)**:
  - 従来のリアルなコーナリング挙動。急ヘアピンのドリフト時に自然にイン側ラインを支えるマイルドなアシスト。
- **強 (超旋回・爽快)**:
  - **面白いほどグイグイ曲がる強力なアシスト**！
  - ステアリングを切った瞬間にノーズがインへ鋭く切り込むクイックピボットと、強力な向心力＆トラクション誘導により、高速コーナーからヘアピンまで吸い付くようにインベタで鋭く旋回できます。
